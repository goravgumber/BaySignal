## Design rules

- Never mark a vehicle exited merely because it left a bay; never vacate an unrelated bay on gate exit.
- For uncertain state, show source, event/received timestamps, freshness, measured confidence and coverage. Omit unavailable measures.
- Label future work `Concept`, illustrative values `Sample data`, simulator events `Simulation`.
- Do not claim achieved model accuracy, uptime, certification, payment completion or vendor connectivity without evidence.
- Keep name editable. Use restrained neutral UI, Inter/system sans, text+icon statuses, no Orbitron/neon/glow, accessible contrast and 44–48px controls. Support 1440×900, 1366×768, ~1024px tablet and 360–430px driver mobile.
